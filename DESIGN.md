# Nocturne playback background experiment

Target: the existing 800 x 480 Car Thing Now Playing screen. Preserve typography, controls, artwork, spacing, other screens, and Minimal Clock behavior.

Spotify references: Elle King uses blue-gray; K.Flay Run for Your Life uses red. Select an artwork background hue using a population-weighted histogram across 64 x 64 pixels, favoring saturated mid/dark perimeter colors over central faces, white text, and near-black pixels. Keep saturation up to 85% and bound the vertical gradient's top lightness to 16-32%, with the bottom at 82% of that value. `packages/ui/src/utils/playbackGradient.ts` owns these values. `SpotifyImage` samples the loaded artwork for Now Playing; the URL-driven gradient path uses the same extractor with a distinct cache key. Other screens retain original extraction and gradients. This approximates the supplied Spotify references; it is not Spotify's proprietary algorithm. The experiment is separate from Minimal Clock PR #60.
